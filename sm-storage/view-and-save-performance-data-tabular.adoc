= SANtricity System Manager에서 표 형식의 성능 데이터를 보고 저장합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 그래프 데이터를 표 형식으로 보고 저장할 수 있습니다. 이렇게 하면 표시하려는 데이터를 필터링할 수 있습니다.

.단계
. 성능 페이지에서 *테이블 보기로 이동*을 클릭합니다.
+
선택한 객체에 대한 모든 성능 데이터가 나열된 테이블이 나타납니다.

. *오브젝트 유형*과 *시간 범위*를 사용하여 표시할 데이터를 선택한 다음 *새로 고침*을 클릭하십시오.
. 열 표시/숨기기 * 단추를 클릭하여 표에 포함할 열을 선택합니다.
+
각 확인란을 클릭하여 항목을 선택하거나 선택 취소할 수 있습니다.

. 표 메뉴에서 *CSV로 내보내기*를 선택하여 표 형식의 보기를 쉼표로 구분된 값(CSV) 파일로 저장합니다.
+
브라우저 설정에 따라 파일이 저장되거나 파일의 이름과 위치를 선택하라는 메시지가 표시됩니다.

+
기본 파일 이름 형식은  `performanceStatistics-<storage array name>-yyyy-mm-dd_hh-mm-ss.csv`이며, 여기에는 스토리지 어레이 이름과 파일이 내보내진 날짜 및 시간이 포함됩니다.
