= SANtricity System Manager에서 선반 보기 순서 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
캐비닛에 있는 쉘프의 물리적 순서에 맞게 하드웨어 페이지에 표시되는 쉘프 순서를 변경할 수 있습니다.

.단계
. 왼쪽 패널에서 menu:Hardware[Controllers and components]를 선택합니다.
. 선반의 드롭다운 목록을 선택한 다음 *순서 변경*을 선택하여 하드웨어 페이지에 표시되는 선반의 순서를 변경합니다.
