= SANtricity 시스템 관리자에서 드라이브 위치 표시등 켜기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Hardware 페이지에서 로케이터 표시등을 켜서 스토리지 배열의 드라이브의 물리적 위치를 찾을 수 있습니다.

.이 작업에 대해
하드웨어 페이지에 표시된 단일 드라이브 또는 여러 드라이브를 찾을 수 있습니다.

.단계
. 왼쪽 패널에서 menu:Hardware[Drives]를 선택합니다.
. 하나 이상의 드라이브를 찾으려면 다음 중 하나를 수행합니다.
+
** *Single drive* -- 셸프 그래픽에서 어레이에 물리적으로 배치할 드라이브를 찾습니다. 드라이브를 클릭하여 컨텍스트 메뉴를 표시한 다음 *Turn on locator light*를 선택합니다.
+
드라이브 로케이터 표시등이 켜집니다. 드라이브를 물리적으로 찾았으면 대화 상자로 돌아가서 * 끄기 * 를 선택합니다.

** *여러 개의 드라이브* -- 필터 필드에서 물리적 드라이브 유형과 논리적 드라이브 유형을 선택합니다. 선택한 조건에 맞는 드라이브 개수가 필드 오른쪽 끝에 표시됩니다. 다음으로 *위치 표시등 켜기*를 클릭합니다. 드라이브의 위치를 확인한 후 대화 상자로 돌아가서 *끄기*를 선택합니다.
